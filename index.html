¿Cómo conectar tu propia cuenta de Gmail?

1. Si deseas usar la app ahora mismo sin configurar nada, ya tienes cargada la Biblioteca Navideña de Prueba y también puedes usar el botón "Subir Audio Local".

2. Para escanear tus subcarpetas reales de Google Drive, pega tu OAuth 2.0 Client ID (de Google Cloud Console con alcance drive.readonly) y opcionalmente el ID de tu carpeta de Navidad.

Es el código al final del enlace de tu carpeta: drive.google.com/drive/folders/ESTE_CODIGO
